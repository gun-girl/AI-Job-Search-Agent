# AI Job Search Agent


An AI-powered job search assistant that collects job opportunities, evaluates their relevance to a candidate's profile, identifies application deadlines, and helps manage applications.
Planned Features
- Customisable candidate profiles
- Flexible job search filters
- Automated job collection
- AI-powered job matching
- Match explanations and missing requirements
- Application deadline tracking
- Job notifications
- Application tracking dashboard
Technology Stack
- Python
- FastAPI
- SQLite
- React
- TypeScript
- OpenAI API
